# Tests

WebDAV test harnesses for the files library, moved out of `data/files/_ASSETS` so they are neither served over HTTP nor shipped to peers that install the library. Run them from the repo root against a running instance.

- `webdav-read-r1/verify.py`, `webdav-write-r1/verify.py`, `webdav-integrated-r1/verify.py`: curl-based assertion suites.
- `webdav-baseline-r1744/reproduce.sh`: rclone baseline.
- `listener/`: standalone Rust test crate and notes for the core HTTP listener changes (belongs with newbound_core, kept here for reference).

The scripts hardcode `http://127.0.0.1:8080/files/dav`. The READMEs describe past runs; the result archives they mention were deleted and are regenerated by re-running the harnesses.
